# Entrega por Feature

Conhecimento de negócio compartilhado → H1 → Functional Spec + critérios de aceitação por Feature → H2 → Technical Spec + Plan → H3 → Issues → código + testes → quality gates → PR → revisão humana.

Cada Feature referencia regras e conceitos compartilhados, sem duplicar toda a base. Mudanças em regra compartilhada demandam análise de impacto nas Features dependentes.
